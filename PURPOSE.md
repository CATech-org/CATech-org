# Purpose

A personal infrastructure project for running open-source LLMs locally, accessible 24/7 over a private WireGuard VPN.

Two collaborators working in parallel, building a self-contained environment for agentic projects using small, open-source models.

## Motivation

Two years of backend and LLM system integration work led to building a dedicated local machine for hands-on experimentation. The goal is to create a self-contained environment for agentic projects using small, open-source models, starting lean and expanding over time (potential Mac Mini addition, GPU upgrades as budget allows).
